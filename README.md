# 📰 Daily & Monthly News Agent (Telegram + Gmail → 10 категорий + Telegraph Instant View + Email)

Автономный аналитический агент на базе **Google Gemini (`gemini-3.1-flash-lite` + `gemini-3.8-flash`)**, работающий в **двух расписаниях**:
1. **Ежедневно в 19:00 (`Asia/Almaty`):** собирает все посты за последние **24 часа** из **59 публичных Telegram-каналов** (с умной подгрузкой статей глубины 1 и дедупликацией двуязычных KZ/RU пар и кросс-канальной копипасты до LLM) и почты **Gmail**, распределяет их по **10 отраслевым категориям**, запускает независимых профильных агентов (`skills/*.md`) с защитой приоритетных источников (Акорда, Правительство, Минпромстрой, Нацбанк), находит межкатегорийные связи и отправляет отчёт в **Telegram (Telegraph Instant View)** и на **Email (HTML-дайджест)**.
2. **Ежемесячно 1-го числа в 09:00 (`Asia/Almaty`):** анализирует все сохранённые ежедневные дайджесты за прошедший месяц (`data/daily_digests/*.json`) и готовит стратегический доклад по макротрендам, динамике всех 10 категорий, идеям автоматизации/локализации и прогнозу на новый месяц.

---

## 🔒 Безопасность
- **Личный Telegram-аккаунт не подключается:** все 59 каналов читаются через публичный веб-интерфейс `t.me/s/<channel>`. Для доставки и заметок используется изолированный Telegram-бот (`@BotFather`).
- **Личная почта не подключается:** для IMAP/SMTP используется выделенный почтовый ящик агента, куда пересылаются только новостные рассылки; готовый HTML-дайджест отправляется на `RECIPIENT_EMAIL`.
- Все ключи и токены хранятся исключительно в локальном `.env` (в `.gitignore`) и в зашифрованных **GitHub Actions Secrets**.

## 📌 База Сохранённых Новостей и База Идей (В 1 клик)
- Под каждым сюжетом в Telegraph есть кнопка **`📌 Сохранить #N в Базу Заметок`**, а под каждой идеей в *Автоматизации* и *Локализации* — **`💡 Сохранить идею #N в Базу Идей`**.
- После нажатия можно написать любой текст в чат с ботом — он прикрепится как **`💬 Моя заметка`**.
- Нажатия автоматически синхронизируются при каждом ежедневном запуске в 19:00, либо в любой момент вручную:
  - В GitHub Actions: запустить `Daily & Monthly News Brief` с `mode = bookmarks` (~15 сек, `$0.00`).
  - Локально: `python -m src.main --sync-bookmarks` (или `--listen-bot` для мгновенного отклика).

## 🚀 Локальный запуск

```bash
source .venv/bin/activate

# Тестовый ежедневный запуск (без отправки в Telegram/Email)
python -m src.main --mode daily --dry-run

# Полный ежедневный запуск
python -m src.main --mode daily

# Ежемесячный стратегический отчёт
python -m src.main --mode monthly

# Синхронизация сохранённых новостей и идей ($0.00)
python -m src.main --sync-bookmarks

# Повторная публикация последнего дайджеста без вызова LLM ($0.00)
python -m src.main --republish-latest
```

## ⏰ Запуск по точному времени (`cron-job.org` → GitHub Actions)

Используется 1 единый workflow `.github/workflows/daily_brief.yml`:
- **URL:** `https://api.github.com/repos/<USER>/<REPO>/actions/workflows/daily_brief.yml/dispatches`
- **Method:** `POST`
- **Headers:** `Accept: application/vnd.github+json`, `Authorization: Bearer <GITHUB_PAT>`, `Content-Type: application/json`
- **Ежедневно в 19:00 (`Asia/Almaty`) — Body:** `{"ref":"main","inputs":{"mode":"daily"}}`
- **1-го числа каждого месяца в 09:00 (`Asia/Almaty`) — Body:** `{"ref":"main","inputs":{"mode":"monthly"}}`
