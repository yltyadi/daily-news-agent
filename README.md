# 📰 Daily & Monthly News Agent (Telegram + Gmail → 8 категорий + Telegraph Instant View + Email)

Автономный агент на базе **Google Gemini (`gemini-3.8-flash`)**, который работает в **двух режимах**:
1. **Ежедневно в 21:00 по времени Алматы (`Asia/Almaty`):** собирает все новости за последние **24 часа** из ваших **60 Telegram-каналов** (включая **полное чтение всех вложенных статей**, `telegra.ph`, Instant View и вложенных постов на глубину до 2 уровней) и почты **Gmail**, распределяет их по **8 отраслевым категориям**, генерирует независимые глубокие разборы через `skills/*.md`, находит межкатегорийные связи и отправляет отчёт в **Telegram (через Telegraph Instant View)** и на **Email (HTML-дайджест)**.
2. **Ежемесячно 1-го числа каждого месяца в 09:00 утра по времени Алматы:** перечитывает все сохранённые за прошедший месяц ежедневные дайджесты (`data/daily_digests/*.json`) и формирует большой **Ежемесячный стратегический доклад (`skills/100_monthly_summary.md`)** с макротрендами, динамикой по всем 8 категориям, структурными сдвигами, топ-идеями для автоматизации и прогнозом на новый месяц.

## 🚀 Как запускать локально

Виртуальное окружение `.venv` уже создано и настроено.

```bash
# 1. Активируйте виртуальное окружение
source .venv/bin/activate

# 2. Ежедневный запуск (тестовый dry-run без отправки в Telegram/Email)
python -m src.main --mode daily --dry-run

# 3. Полный ежедневный запуск (публикация в Telegraph + отправка в Telegram и Email + сохранение в архив месяца)
python -m src.main --mode daily

# 4. Ежемесячный итоговый запуск (анализирует все сохранённые дайджесты из data/daily_digests/)
python -m src.main --mode monthly
```

## ⏰ Расписание в GitHub Actions (`.github/workflows/daily_brief.yml`)

В workflow уже прописаны оба запуска (по времени Алматы `UTC+5`):
- **Каждый день в 21:00 Алматы (`0 16 * * *` UTC):** запускается `--mode daily`, отправляет ежедневный дайджест и автоматически сохраняет копию в `data/daily_digests/digest_YYYY-MM-DD.json`.
- **1-го числа каждого месяца в 09:00 утра Алматы (`0 4 1 * *` UTC):** запускается `--mode monthly`, перечитывает все дайджесты за месяц и отправляет итоговый месячный аналитический доклад.

### Как настроить `cron-job.org` для запуска секунда-в-секунду (Бесплатно)
Создайте 2 бесплатных расписания на [cron-job.org](https://cron-job.org/) (часовой пояс `Asia/Almaty`):
- **URL (одинаковый для обоих):**
  `https://api.github.com/repos/<ВАШ_ЛОГИН>/<ИМЯ_РЕПО>/actions/workflows/daily_brief.yml/dispatches`
- **Method:** `POST`
- **Headers:**
  - `Accept`: `application/vnd.github+json`
  - `Authorization`: `Bearer <ВАШ_GITHUB_TOKEN>`
  - `Content-Type`: `application/json`
- **Задача 1 (Ежедневно в 21:00 Asia/Almaty) — Body:**
  ```json
  {"ref":"main","inputs":{"mode":"daily"}}
  ```
- **Задача 2 (1-го числа каждого месяца в 09:00 Asia/Almaty) — Body:**
  ```json
  {"ref":"main","inputs":{"mode":"monthly"}}
  ```
